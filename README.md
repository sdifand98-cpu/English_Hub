# English Hub – A1

## تشغيل المشروع على Windows

1. فك ضغط الملف في مجلد واضح.
2. افتح PowerShell داخل **نفس المجلد الذي يحتوي على `package.json`**.
3. نفّذ الأوامر التالية بالترتيب:

```powershell
npm.cmd install
npm.cmd run dev
```

4. افتح رابط Local الذي يظهر في PowerShell، وغالبًا يكون `http://localhost:5173`.

> إذا ظهر خطأ `package.json not found` فهذا يعني أن PowerShell مفتوح في المجلد الأب. استخدم `dir` وتأكد أن `package.json` ظاهر قبل تشغيل npm.
